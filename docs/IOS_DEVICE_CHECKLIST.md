# iPad／iPhone 實機測試清單（給 Tim）

自動測試只在 Chrome 無頭瀏覽器模擬 iPad 尺寸和觸控，下面這些只有真的 iPad Safari 才測得到。每一項照「怎麼做 → 應該看到／聽到」測；不對的話，記下**項目編號、iPad 型號與 iPadOS 版本、是在 Safari 分頁還是主畫面圖示**，能錄影最好，交給助理。

- **主要裝置是 iPad**，直放、橫放都要試，A–H 全做。iPhone 只看 A1、C1 有沒有破版、文字或按鈕被切掉。
- **前提**：要先把網站放上 GitHub Pages（https）。iPad 用區網 `http://<電腦 IP>:8000/` 也能開，但不是 https，service worker 不會啟用，**E、F 兩段測不了**；其他段可以先在區網測。見 `docs/RELEASE_CHECKLIST.md`。
- **打開聲音**：側邊／控制中心的靜音關掉、音量調大。A4 專門測靜音。
- 括號裡是這一項的來源，助理看得懂就好。

## A. 第一次開啟與聲音

- [ ] **A1** 用 Safari 打開網址：首頁有「單字」「生活句子」兩個大按鈕、左下角的音符按鈕；畫面沒有被切掉，直放、橫放都要看。
- [ ] **A2** 按「單字」：**第一下**就聽到中文說明（女聲預錄），不是機器朗讀的聲音。點一個主題、點圖片：聽到英文單字。（HANDOFF「語音（iOS 注意事項）」）
- [ ] **A3** 句子卡：點圖片會念整句英文；把「中」打開，念完英文會接著念中文，順序不會亂、不會互相蓋掉。（HANDOFF 已知限制：排在中文後面的錄音）
- [ ] **A4** 打開靜音鍵（或控制中心的鈴鐺）再玩一下：Tim 決定靜音鍵下**照樣出聲**（第 8 階段，`navigator.audioSession = 'playback'`，iPadOS 16.4／17 以後）。預期按鈕「啵」聲、答對「叮」、中文說明、英文朗讀、背景音樂都有聲音。如果有哪一種沒聲音，記下 iPadOS 版本。（health-audit 第 5 項）
- [ ] **A6** 音量平衡：看一張單字卡（英文）→ 玩一題聽音找圖答對（「好棒」之類的中文稱讚）→ 句子卡開「中」看一張（英文接中文）。中文和英文聽起來**差不多大聲**嗎？如果英文還是明顯比較大聲，告訴助理（可以調 `EN_VOLUME` 或把中文重做成 −14 LUFS，不用重錄）。（第 8 階段第 3 項）
- [ ] **A5** 聽音找圖：答對後，下一題的英文會**自動**念出來。如果沒有聲音，按右上角黃色喇叭能不能再聽到？（HANDOFF 階段 4 修正）

## B. 觸控

- [ ] **B1** 點單字卡圖片：圖片只**左右搖**，不會轉一整圈；連點很多下也不會越搖越亂。
- [ ] **B2** 長按圖片（主題卡、首頁插圖、單字卡）約 2 秒：**不會**跳出「儲存影像／分享」選單。（health-audit 第 9 項）
- [ ] **B3** 雙指捏合放大：整個畫面**不會**放大。（health-audit 第 9 項）
- [ ] **B4** 連連看：手指拖線從圖拉到另一邊，線跟著手指走，放開時判斷對錯。

## C. 遊戲一輪

- [ ] **C1** 單字卡：看完一個主題，有稱讚，星星罐多一顆。
- [ ] **C2** 聽音找圖、連連看、翻牌記憶各玩完一輪（故意答錯一次）：答錯有溫和提示、會再念一次；最後有星星結算；「再玩一次」可以用。
- [ ] **C3** 翻牌記憶：翻錯的兩張**一定會自己翻回去**（約 1 秒）。如果卡住不翻回去，請記下是第幾輪、是從「今日複習」還是一般遊戲進去的，翻牌前做了什麼。（health-audit 第 2 項：原因還沒找到）
- [ ] **C4** 生活句子：句子首頁上面是「玩遊戲」星星鈕，下面是「今日複習」和「句子卡」。句子卡用左右箭頭或滑動看完 7 張，罐子多一顆；「玩遊戲」裡的聽句子找圖、排句子、今日複習各玩一輪。排句子排完整句才出現英文字。
- [ ] **C5** 玩到一半按 Home 鍵或切到別的 App，過一下再回來：聲音沒有卡住，還可以繼續點、繼續答。（health-audit 第 1、3、4 項）
- [ ] **C6** 玩的時候有來電（或叫 Siri）再回來：同 C5，不會一直沒聲音。

## D. 背景音樂（第 8 階段）

- [ ] **D1** 打開網站，還沒點任何東西時是安靜的；按「單字」或「生活句子」之後，背景音樂在 1 秒內慢慢出來，聲音很小、不吵。
- [ ] **D2** 念中文說明或英文單字時，音樂**自動變小**；念完過一下才慢慢回來。中文說明接英文單字的中間，音樂不會突然變大。
- [ ] **D3** 首頁左下角的音符按鈕：點一下音樂淡出、按鈕變成有斜線的淡色音符；再點一下音樂回來。關掉後重新整理，還是關的。
- [ ] **D4** 玩到一半按 Home 鍵或鎖定螢幕：音樂停。回來後點任何一個按鈕，音樂接著播。來電、叫 Siri 之後也一樣。
- [ ] **D5** 從主畫面圖示開、開飛航模式：音樂照樣有（音樂是程式產生的，不用下載）。

## E. 加到主畫面、離線（要 https）

- [ ] **E1** Safari → 分享 → 「加入主畫面」：圖示是獅子，名稱是「看圖學英文」。
- [ ] **E2** 從主畫面圖示打開，**全部畫面點過一次**（單字、句子、三個遊戲），讓聲音都載入過。
- [ ] **E3** 完全關掉 App（從 App 切換器往上滑掉）→ 開飛航模式 → 從圖示打開：能開、能玩三個遊戲、中文說明有聲音、英文單字有聲音（用 iPad 內建語音）。（HANDOFF 已知限制；phase-6 報告）
- [ ] **E5** 注意：**Safari 分頁和主畫面 App 的進度是分開的**。以後都從主畫面圖示開，進度才不會分成兩份；只在 Safari 玩而且超過 7 天沒開，Safari 可能會清掉資料。這一項不用測，知道就好。（health-audit 第 6 項）

## F. 有新版本時（要 https，等助理通知「新版已推送」再測）

- [ ] **F1** 新版推送後，從主畫面圖示打開，**正在玩遊戲時**：不會突然跳回首頁或重新載入。
- [ ] **F2** 回到首頁：App 自動重新整理一次，之後是新版；星星、進度、Aa／中 和音樂開關都還在。（health-audit 第 3 點第 3 項）

## G. 輔助功能（大概看一下就好）

- [ ] **G1** 設定 → 輔助使用 → 動態效果 → 打開「減少動態效果」：點圖片不搖，只會亮一下；答對沒有星星飛出去；每個遊戲照樣玩得完。
- [ ] **G2** 設定 → 輔助使用 → 顯示與文字大小 → 「增加對比」：字和框線更深，沒有東西看不見。
- [ ] **G3** VoiceOver（三下側邊按鈕或設定開啟）：在首頁左右滑，會念「單字 Words」「生活句子 Phrases」「背景音樂 Music」；進到下一個畫面時，VoiceOver 的框會跳到新畫面裡，不會停在看不見的地方。

## H. 清除學習進度（家長用，第 8 階段起遊戲裡沒有按鈕）

- 要讓進度、星星罐從頭開始：
  - Safari 分頁：設定 → App → Safari → 進階 → 網站資料 → 找到這個網站（github.io）→ 刪除。
  - 主畫面 App：刪掉圖示，再從 Safari 重新「加入主畫面」。
- 這兩種都會連離線檔案一起清掉，下一次打開需要網路。Aa／中、音樂開關也會回到預設。
- 舊版家長專區加過的字和照片也會一起清掉（第 8 階段起畫面上已經看不到，只是還留在 iPad 裡）。
